# One Line, No Deadline Met

Entry for the [make.fun bounty "One Line, No Deadline Met"](https://make.fun/bounty/u-markk-st-one-line-no-deadline-met-6adc00ce): one original single-line joke giving an excuse for a missed deadline, under 200 characters.

## The entry

> I finished at 11:58, but my laptop chose that exact moment to update, restart, and take my finished file with it on a journey of self-discovery.

144 characters, one line, no setup line, no link, no picture.

## How it works

`main.py` (Python 3.13) writes that single line to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt` when the variable is set).

```sh
python3 main.py
```
